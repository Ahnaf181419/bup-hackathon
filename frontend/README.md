# Frontend — React (built with Lovable)

This folder holds the React app generated by [Lovable](https://lovable.dev).
The backend team does NOT hand-write React code here — it comes from Lovable.

## Workflow

1. Build/iterate the UI in Lovable.
2. Export / sync the generated code into this folder.
3. Wire it to the backend (below) — this part is manual.

## Backend connection

| Setting    | Value (dev)                          |
| ---------- | ------------------------------------ |
| API base   | `http://localhost:3001/api`          |
| Auth base  | `http://localhost:3001/api/auth`     |
| Credentials| `include` (session cookies)          |

## Wiring checklist (do once after every Lovable export)

1. Ensure API calls use a single base URL constant, e.g. `VITE_API_URL=http://localhost:3001/api`.
2. Install the Better Auth client: `npm install better-auth`.
3. Create the auth client using the snippet in `../docs/better-auth-setup.md`.
4. Guard pages that need auth; redirect signed-out users to `/login`.
5. Only call endpoints listed in `../docs/api-contract.md`.

## CORS note

The backend allows origins listed in its `CORS_ORIGIN` env var.
When Lovable gives you a preview domain, add it to `backend/.env`:

```
CORS_ORIGIN=http://localhost:5173,https://your-lovable-preview.lovable.app
```
